# torch-onnx 2.15.1

This patch fixes `fill_diagonal_` export in the standalone backend and corrects
optional-package tests that assumed newer ONNX schemas were executable on ORT.

## Fixed: diagonal-fill export

`x.clone().fill_diagonal_(...)` previously failed because functionalization
produced `prims.as_strided_scatter` without a registered translation. Native
lowering for both aten and prims `as_strided_scatter` now uses ONNX
`ScatterElements`, without a Transformers FX patch.

The regression suite covers square, rectangular and higher-dimensional diagonal
fills, `wrap=True`, float/integer inputs, empty inputs and dense transposed bases.
The underlying strided-write lowering also covers dynamic sizes/strides,
nonzero static storage offsets, noncontiguous update values, unchanged input
values and save/reload at opsets 20 and 28. Base tensors with storage holes or
unknown dense storage order remain unsupported and are rejected explicitly.

See [PR #237](https://github.com/justinchuby/torch-onnx/pull/237) and
[Transformers #51305, item 6](https://github.com/huggingface/transformers/issues/51305#6-no-translation-for-fill_diagonal_).

## Corrected: optional-package runtime coverage

ORT 1.32 lacks RoiAlign-22 and DequantizeLinear-28 kernels. PS ROI Align and
zero-point-free dequantization tests now validate default-opset-28 graphs with
ONNX reference execution and retain explicit opset-20 ORT execution. This fixes
the CI expectations; it does not add an exporter workaround or an ORT kernel.
See [PR #236](https://github.com/justinchuby/torch-onnx/pull/236).

## Validation

- 162 related regressions and 142 subtests passed locally.
- All 37 new strided-write tests passed with PyTorch 2.10 and 2.15; the tests are
  included in the annual PyTorch compatibility CI matrix.
- The complete optional-package selection passed locally: 93 tests.

The default remains opset 28. PyTorch dependency and compatibility policy are
unchanged. The experimental scope and runtime boundaries described in the
[2.15.0 notes](2.15.0.md) continue to apply.
